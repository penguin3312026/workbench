三种使用方式

  1. 在线自测：在当前页「在线自测」标签直接勾选 10 题，立即看个人结果。
  2. 问卷星采集 + 批量分析：把团队成员填写问卷星后的答卷导出 CSV，拖入下方「CSV 分析器」出团队报告。
  3. 编辑/查看原始数据：登录问卷星编辑问卷，修改题目或查看实时统计。

❓ 填完问卷星的人能看到自己的分析结果吗？

目前不能直接看到。问卷星提交后默认只显示「提交成功」感谢页，不会自动弹出管理方格坐标和改善建议。

推荐三种解决方案：

  1. 最省事：让填写者先在本页「在线自测」做一遍，提交后直接看结果（与问卷星题目一致）。
  2. 管理员分发：在问卷星里加一道「姓名/部门」题，导出 CSV 后用本页「CSV 批量分析」算分，再把每个人的报告单独发过去。
  3. 自动推送（进阶）：开通问卷星「数据推送」把每份答卷实时推送到本机代理，自动算分后发邮件/企业微信给填写者（需额外部署与消息通道）。

一键导入到问卷星

点击下方按钮，即可用当前题目在当前账号创建一份新问卷并发布。Key 只发给本地代理，不会上传到其他地方。

如何开启「获取微信用户信息」

API 创建问卷时不能自动开启微信授权，必须登录问卷星后台手动设置：

  1. 进入问卷 → 顶部「设置」→「填写限制」。
  2. 勾选「获取微信用户信息」。
  3. 选择「获取微信用户的昵称 & OPENID（需登录）」。
  4. 收集方式选「必须登录才能填写」。
  5. 授权方式选「通过问卷星官方微信认证服务号来收集」（无需自己绑定服务号）。
  6. 保存后重新发布。导出 CSV 时就会出现「微信昵称」「微信OpenID」「微信头像」等列，分析器会自动识别并在逐人结果中显示。

已创建的问卷，可直接在编辑页打开「设置」开启；不需要重新导入。
